# FlashMusic 🎧

Uma interface responsiva para descobrir músicas, artistas e produtores de diferentes países. O catálogo é carregado da API pública de busca da iTunes Store; quando disponível, cada faixa pode ser ouvida em uma prévia curta e aberta na loja.

## Recursos
- Descobertas iniciais em mercados dos EUA, Reino Unido, África do Sul, Brasil, Japão, Índia, México, França, Alemanha e Austrália, além de uma seleção de K-pop
- Seleções de pop, sons africanos, K-pop, J-pop, música indiana, ritmos latinos, eletrônica, hip-hop e indie
- Busca de músicas e artistas no catálogo internacional
- Filtros por estilo e perfis de artistas encontrados no catálogo
- Seleção editorial de produtores internacionais para conhecer
- Player de prévias com progresso, volume, aleatório, repetição e navegação
- Faixas curtidas salvas no navegador
- Layout responsivo para desktop e dispositivos móveis

## Executar localmente
Abra `index.html` no navegador ou inicie um servidor local com uma ferramenta como a extensão Live Server do VS Code. É necessária uma conexão com a internet para carregar o catálogo, as capas e as prévias.

## Catálogo e áudio
As faixas, artistas, capas, links e prévias são obtidos da API de busca da iTunes Store. A disponibilidade varia conforme a região e algumas faixas não têm prévia. A FlashMusic não hospeda nem fornece o catálogo completo de áudio. Os produtores em destaque são uma seleção editorial de nomes internacionais, não perfis de usuários ou uma alegação de parceria.
