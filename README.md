# FlashMusic 🎧

Plataforma de descoberta musical com interface responsiva, tema escuro e player de áudio.

## Recursos
- Interface responsiva para desktop e dispositivos móveis
- Busca por música, artista e gênero
- Navegação por estilos musicais
- Player com play/pause, faixa anterior/próxima, progresso e volume
- Modos aleatório e repetição
- Favoritar faixa durante a sessão
- Criação de playlists locais durante a sessão

## Tecnologias
- HTML5
- CSS3
- JavaScript
- Lucide Icons

## Executar localmente
Abra o arquivo `index.html` no navegador. Para desenvolvimento, também é possível iniciar um servidor local, por exemplo com a extensão Live Server do VS Code.

## Observação sobre o áudio
As faixas de demonstração usam arquivos de exemplo hospedados pelo SoundHelix. Elas servem para testar o player e podem ser substituídas por arquivos próprios ou por fontes licenciadas. O projeto não inclui catálogo comercial, contas de usuário ou backend nesta versão.
